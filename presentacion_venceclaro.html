1. El Agente Coordinador y sus 5 Skills (con Estructura de Archivos)

Implementación determinista: una única entidad orquestadora con estado (Stateful) coordina cuatro unidades operativas atómicas y sin estado (Stateless).

Seleccioná una Skill para auditar:
🤖 AgenteVencimientos (core/agent.py) Contiene la máquina de estados y el buffer acumulador. Invoca las skills a través de core/skill_loader.py.

🎯 organizar-vencimientos

Rol: Coordinadora de ciclo de vida, ingesta acumulativa y supervisión humana

Stateful (Con Estado)

Coordina la ejecución secuencial determinista. Mantiene el lote acumulado de facturas, gestiona la pregunta interactiva de si se desean sumar más comprobantes, entrega los datos al usuario en el Punto de Control y delega el ordenamiento, exportación y despacho.

📁 Estructura de Archivos de la Skill: Convención Modular de la Cátedra 
skills/organizar-vencimientos/
├── SKILL.md                      # Procedimiento normativo, roles y especificación
├── references/
│   └── politica-orquestacion.md  # Políticas de handoff humano, bloqueo y trazabilidad
├── orquestador.py                # Lógica ejecutable de coordinación
└── scripts/
    ├── ejecutar.py               # CLI Python (--auto-confirmar, --salida, --json)
    └── ejecutar.sh               # Wrapper ejecutable Bash portable
📥 Entradas: Colección de PDFs en memoria o rutas de disco.
📤 Salidas: Agenda consolidada, archivos excluidos y auditoría.
⛔
Regla de Oro (Lo que NUNCA debe hacer):

No contiene heurísticas de bajo nivel de PDF por regex, no ordena listas internamente y no escribe líneas de texto CSV.

Paso 1: Diálogo de Ingesta Acumulativa

ESTADO: INICIAL / EXTRAYENDO

El usuario puede cargar facturas una por una o en lotes. El orquestador mantiene el lote acumulado en memoria sin reiniciar la sesión y pregunta explícitamente: "¿Deseás seguir cargando más facturas o avanzar a la revisión?".

// Ingesta interactiva en app.py:
agente.agregar_archivos([("factura_edesur.pdf", bytes)])
Lote acumulado: 1 factura. Orquestador: ¿Desea sumar otra factura? [Sí] [Avanzar]
agente.agregar_archivos([("factura_telecom.pdf", bytes)])
Lote final: 2 facturas listas para revisión conjunta en una sola agenda.
Cero alucinación: ante campos vacíos o ambiguos, el flujo se bloquea hasta confirmación. Hacé clic en los pasos 1, 2, 3 o 4 para auditar cada fase ➔
Integración Externa & Calidad de Software

3. Despacho por Correo (Gmail API) y Resiliencia Educativa

Consumo seguro de servicios externos para la entrega de la agenda, complementado con un simulador educativo para evaluación docente.

📧 Skill: enviar-agenda

Gmail TLS 587

Despacha la agenda vía SMTP seguro de Gmail utilizando una Contraseña de Aplicación de 16 caracteres, garantizando que nunca se exponga la contraseña personal del usuario.

Estado: Listo para simular o enviar.
🔒 Seguridad: Credenciales protegidas en .env; nunca se registran en logs ni se exponen a terceros.
Verificación Automatizada 25 / 25 PASSED (100%)

Suite Completa de Pruebas con pytest

  • ✓ Ingesta incremental de facturas y descarte de duplicados.
  • ✓ Ordenamiento cronológico con desempate estable por empresa.
  • ✓ Delimitador regional ; y codificación UTF-8 con BOM para Excel.
  • ✓ Segregación estricta de monedas (ARS y USD nunca mezcladas).
  • ✓ Validación de correo y empaquetado MIME multipart con adjunto.
⭐ Valor Académico Agregado

Sandbox para Corrección Docente

Si el profesor ejecuta el trabajo sin haber cargado sus credenciales de Gmail, la skill detecta la ausencia y activa el Sandbox Simulado, empaquetando el CSV y confirmando la validez sin provocar errores ni interrumpir la evaluación.

CLI: python skills/enviar-agenda/scripts/ejecutar.py --destino mail@test.com --dry-run
